JavaScript Practice Assignment

Topic: Variables, Arithmetic Operators, and Conditional Statements

QUESTION 01

First and Last Name

Create two variables: firstName and lastName. Store your first and last name in them and print your full name.

QUESTION 02

Arithmetic Operations

Create three variables: num1, num2, and num3. Perform the following operations using all three values:

  • Addition
  • Subtraction
  • Multiplication
  • Division

Display the result of each operation.

QUESTION 03

Temperature Checker

Take the temperature from the user.

  • If the temperature is 0°C or below, print "Freezing".
  • Otherwise, print "Not freezing".
QUESTION 04

Age Category

Take the user's age and display the appropriate category:

  • 0–12: Child
  • 13–19: Teenager
  • 20–59: Adult
  • 60 and above: Senior Citizen
QUESTION 05

Electricity Bill Calculator

Take the number of electricity units consumed and calculate the bill using these rates:

  • First 100 units: Rs. 10 per unit
  • Next 100 units: Rs. 15 per unit
  • Above 200 units: Rs. 20 per unit

Calculate the bill using cumulative rates. The first 100 units are charged at Rs. 10 each, and only the units above 100 are charged at the next rate.

QUESTION 06

Traffic Light

Take a traffic light color as input.

  • Red: "Stop"
  • Yellow: "Ready"
  • Green: "Go"
  • Any other color: "Invalid Color"
QUESTION 07

Pocket Money Checker

Take the amount of pocket money.

  • If it is greater than Rs. 500, print "You can buy a gift".
  • Otherwise, print "Save your money".
QUESTION 08

Free Delivery Checker

Take the total shopping amount.

  • If it is Rs. 2,000 or more, print "Free Delivery".
  • Otherwise, print "Delivery Charges Apply".

How to Check the Result

Follow these steps to check the output of the JavaScript programs:

01

Open the JavaScript File

Open the JavaScript file in your code editor and make sure the code is saved.

02

Open the HTML Page

Open the HTML file in Google Chrome or another web browser.

03

Open Developer Tools

Right-click on the webpage and select Inspect.

04

Go to the Console

Click the Console tab in Developer Tools to view the JavaScript output.

05

Check the Output

Run the JavaScript program and check the result displayed in the Console.

Note: If the program uses prompt(), enter the requested value when the popup appears. The result will be displayed in the Console.
